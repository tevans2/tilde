~ Tilde prototype

The query bar, typed path, select mode, text mode and activity feed combined into one window. Click into the window to start. It opens in GO mode, where typing searches. The files are made up.

    Decisions this prototype makes

    1. One bar for both the path and search. Results split into Here and Everywhere.
    2. Space separates search terms. tab or / goes into a folder. In the earlier mockup space went into a folder, but that clashes with multi-word search.
    3. Three modes: GO (typing), SELECT (single keys), EDIT (text). esc steps down, / goes back up.
    4. Rename and new item switch to EDIT on that line automatically, and ⏎ applies. Text mode is how you change names.
    5. Actions apply to the shelf when it has items, otherwise to the highlighted row.
    6. The search filter carries into SELECT, so typing, then esc a m, moves every match.
    7. Activity is a place: @ goes there, it shows in the path bar, and ⌫ comes back.
    8. One undo history covers everything, including batches applied from text mode.

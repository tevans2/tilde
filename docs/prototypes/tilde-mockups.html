~ Tilde mockups

Six ways to navigate files from the keyboard. Each window is live: click into it and use the keys listed beside it. The files are made up but shared, so a file you move in one mockup has moved in all of them.

tilde · search everything
Saved views
❯

    Every view is a search

    There is no current folder. Opening a folder just adds in: to the query. An empty query shows what you use most and most recently.

    Jobs it targets

    Get back to a known fileFind recent filesPreview

    Try

    • Type inv, then in:fin to narrow it
    • tilde swift matches across the path
    • ext:pdf mod:<7d or size:>100M
    • ⌥1–⌥4 load saved views
    • tab opens actions, then m to move

    Trade-offs

    • Weak for browsing a folder you don't know
    • Needs a global index, and ranking has to be excellent or you stop trusting it

    Open question

    Should an empty query show recents (as here) or your home folder?
    tilde · typed path

    The path is a line you type

    Each path segment fuzzy-matches the folders inside the current one. With practice, dev pro til becomes muscle memory. The columns show where you are and what's next.

    Jobs it targets

    BrowseGet back to a known file

    Try

    • Type dev space pro space til ⏎
    • ⌫ on an empty segment goes up one level
    • ↑↓ pick a different match
    • ' then d jumps to the Downloads mark
    • ~ goes home

    Trade-offs

    • You still need to know roughly where a file lives
    • Deep trees cost one step per level

    Open question

    Should a segment match only direct children (as here) or any descendant, so you can skip levels?
    tilde · shelf
      Shelf
        jk movehl folderx collecta collect allu undoesc clear shelf

        Collect first, then act once

        The selection is a shelf that stays put while you move between folders. Each action is one key. Actions that need a destination open the same fuzzy jumper.

        Jobs it targets

        Act on filesOrganize

        Try

        • x on two files in Downloads
        • l to Desktop, x a screenshot
        • m, type arch, ⏎
        • u to undo the move

        Trade-offs

        • Single-letter actions need a mode where typing doesn't search
        • A shelf that outlives navigation can surprise people ("what's still selected?")

        Open question

        Should the shelf survive a restart, like a clipboard you can see?
        tilde · activity
          jk move1–5 filteri inboxf file it⏎ open⌫ trash

          Files arranged by time, not place

          A feed of what arrived or changed, tagged by where it came from. Inbox mode shows only what's still sitting in Downloads or on the Desktop, so tidying up becomes working through a list.

          Jobs it targets

          Find recent filesOrganize

          Try

          • i for inbox mode
          • f on the invoice, type fin 26, ⏎
          • 3 shows only screenshots

          Trade-offs

          • Needs a persistent history of file events (FSEvents makes this feasible)
          • "Where from" metadata is missing for some downloads

          Open question

          Is this a main view, or just a saved query in concept A?
          tilde · edit folder as text
          ~/Downloads/Edit freely. Nothing changes until you apply.
          Pending changes
          Rename: edit a nameTrash: delete the lineMove: type a pathNew folder: end a line with /

          A folder is a text file

          Your editor skills become file operations: multi-cursor, find and replace, and deleting lines all work. As you type, the panel on the right shows exactly what will happen.

          Jobs it targets

          OrganizeBulk rename

          Try

          • Rename dataset-2026-10.zip to anything
          • Delete the Figma-Installer.dmg line
          • Change a line to ~/Archive/receipt_8841.pdf
          • Add a line receipts/
          • ⌃S to apply

          Trade-offs

          • This mockup matches lines by position. A real version needs hidden IDs per line (as oil.nvim does) so reordering can't confuse a rename with a delete.
          • Powerful enough that the review step is mandatory

          Open question

          Is this the default way to view a folder, or a mode you switch into?

            Summoned, not opened

            A floating panel on a hotkey, like Spotlight or Raycast. It makes handing files to other apps work from the keyboard, which is where keyboard-driven tools usually fall back to the mouse.

            Jobs it targets

            Hand off to other appsGet back to a known file

            Try

            • Summon, type contract
            • tab to switch to actions, then a to attach it to the message
            • Collect two files with tab s, then attach both
            • o types the path into a system Open dialog

            Trade-offs

            • Driving other apps needs Accessibility permission
            • A panel is cramped for organizing, so you'd likely also want a full window

            Open question

            Panel only, window only, or both? The tab switch here is one answer to the modal question: typing searches, and tab turns letters into actions.
